## Featured Work — Module 9: Sales Guru+ Final Project

For the final development project, I enhanced an existing **Java Spring Boot** application that originally managed companies and sales representatives. The expanded **Sales Guru+** application supports:

- **Sales data:** PostgreSQL storage for products, invoices and invoice line items.
- **Business logic:** Invoice validation, company–representative checks and aggregated invoice details.
- **Security:** Database-backed authentication and HTTPS-protected endpoints.
- **User interface:** Thymeleaf pages for viewing companies, representatives, products and invoices.
- **Testing:** Five passing Maven/JUnit tests and 15 passing end-to-end integration checks.

The Module 9 submission also documents requirements, development methodology, software design, database relationships, verification results and ongoing maintenance considerations.

**Technologies:** Java 21 · Spring Boot 3.5.6 · Spring Data JPA · Spring Security · PostgreSQL · Thymeleaf · Maven · JUnit 5 · Mockito
